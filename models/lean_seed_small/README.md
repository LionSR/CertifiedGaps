# Small Lean seed certificates (Task 5)

This is a **partial certification project**, pinned to Lean `v4.35.0-rc3` and the same
Mathlib commit as `../../lean/`. No model seed has been made unconditional here.

The selected model is the longitudinal Ising ring
`H = -Σ ZZ - (1/4) Σ X - (1/20) Σ Z`, in the Pauli-Z RP basis, with seed
`(n₀, β₀) = (6, 97/4)`. The exact original targets are
`εₛ = 9064/10⁹`, `εₜ = 3141/10⁸`. A completed seed proof would feed the existing
chain certificate and give `Δ_L > log(13480)/(97/4)` for even `L ≥ 6`.

Read [REPORT.md](REPORT.md) for results, the remaining proof obligations, costs, and priorities.
[inventory.tsv](inventory.tsv) covers all 43 parameter points. Its spectral cutoffs and
runtime estimates are explicitly **non-certifying**.

## Contents and trust boundary

- `certify.jl`: **untrusted** Julia/LAPACK search, followed by exact integer proposals;
  writes `certificate.json` and `LeanSeedSmall/Generated.lean`.
- `Checker.lean`: direct integer Hamiltonian action and scalar residual/Gram checker.
- `Packed.lean`: packed implementation and 56-to-288-bit expansion recipe; its general
  lane-decoding correctness proof remains open.
- `Generated.lean`: `decide +kernel` proofs of the generated packed checks at 6/12 sites,
  the direct 6-site check, and direct classical counts at 6/12 sites.
- `GeneratedChunks.lean`: independent direct 12-site arithmetic in 64 blocks and exact
  enumeration coverage; generated by `chunks.jl`. `NegativeChecks.lean` checks rejection
  of bad proposals in the kernel.
- `ChunkCoverage.lean`: ties the generated block list to a fixed, complete enumeration.
- `Arithmetic.lean`: kernel-checked endpoint arithmetic for the exact seed constants.
- `ResidualLemma.lean`: the weighted finite-sum part of the spectral residual argument.
- `SeedBridge.lean`: the **exact original RPRing seed conclusions**, conditional on four
  explicitly listed log-partition enclosures. It does not use the original seed sorries.
- `prepare_vendor.jl`: copies original Lean sources into an ignored local build tree,
  records their hashes, and narrows only `ProductLimit`'s copied import header.
- `check.jl`, `test/runtests.jl`: exact Julia replay and mutation checks, useful diagnostics
  but not part of the logical trust base.

`#print axioms` is included in the Lean modules. Conditional hypotheses remain obligations
even when the axiom list contains only Lean's standard axioms.

## Reproduce

With Julia 1.12 and the pinned Lean toolchain on `PATH`, from this directory:

```sh
export OPENBLAS_NUM_THREADS=1
export JULIA_DEPOT_PATH="$PWD/.julia"
export XDG_CACHE_HOME="$PWD/.tools/cache"
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. prepare_vendor.jl
lake exe cache get
lake build
julia --project=. check.jl
julia --project=. test/runtests.jl
LAKE_EXE="$(command -v lake)" julia --project=. validate.jl
```

`lake exe cache get` was attempted first in this environment; its host was blocked by the
network policy, so the build used source compilation. If that happens, `lake --no-cache build`
is sufficient. All build output stays here; `../../lean/` is never used as a build directory.

To regenerate proposals and non-certifying research tables:

```sh
julia --project=. certify.jl
julia --project=. chunks.jl
julia --project=. inventory.jl
julia --project=. feasibility.jl
julia --project=. costs.jl
lake build
```

Set `LEAN_EXE` for `costs.jl` when Lean is not installed at this session's local tool path.
`Audit.lean` prints the axiom dependencies of every claim at the trust boundary.
Generation took about 13 seconds for the 4096-dimensional dense solve. The successful
compact arithmetic module built in about 53 seconds in a concurrent source build, mostly
the scalar 12-site classical count. The direct 12-site chunk module built in 123 seconds.
These times exclude Mathlib installation/compilation.
